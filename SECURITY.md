# Sicherheitsprobleme privat melden / Report security issues privately

Bitte melde Sicherheitsprobleme per E-Mail an [hybrid-larval-1l@icloud.com](mailto:hybrid-larval-1l@icloud.com?subject=Turniermanager%20security). Eröffne dafür kein öffentliches Issue und veröffentliche keine Zugangsdaten oder ausnutzbaren Details.

Nenne Appversion, Betriebssystem, den betroffenen Ablauf und möglichst kurze Schritte mit synthetischen Daten. Schicke zunächst keine vollständigen Backups, Teilnehmerdaten, Passwörter oder Tokens mit. Falls weitere Informationen nötig sind, stimmen wir eine begrenzte Übermittlung ab. Es gibt keine zugesagte Antwortfrist oder Prämie.

Please email security reports to [hybrid-larval-1l@icloud.com](mailto:hybrid-larval-1l@icloud.com?subject=Turniermanager%20security). Do not open a public issue or publish credentials or exploitable details.

Include the app version, operating system, affected workflow and short reproduction steps using synthetic data. Do not attach complete backups, participant data, passwords or tokens initially. If more information is needed, we will agree on a limited transfer. No response deadline or reward is promised.

Für normale Bedienfehler und Vorschläge verwende die [öffentlichen Formulare](https://github.com/arnefranz-del/turniermanager-beta/issues/new/choose). / For ordinary bugs and suggestions, use the [public forms](https://github.com/arnefranz-del/turniermanager-beta/issues/new/choose).
